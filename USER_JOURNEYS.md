# FounderMind User Journeys

This document outlines the key user journeys through FounderMind, showing how different features work together to create cohesive experiences.

## Journey 1: First-Time Visitor → Engaged User

**Goal:** Convert a curious visitor into an active FounderMind user

### Path A: Beginner Founder

1. **Landing Page** (`/`)
   - Sees compelling value proposition
   - Reads feature cards (AI Advisors, Simulation, Competition)
   - Clicks "Try Demo" to experience the product

2. **Onboarding Flow** (Auto-triggered for new users)
   - Step 1: Welcome screen explains FounderMind
   - Step 2: Chooses "I'm New to Startups"
   - Step 3: Tour of Dashboard feature
   - Step 4: Introduction to AI Advisors
   - Step 5: Preview of Competition mode
   - Completes onboarding → Redirected to Dashboard

3. **First Dashboard Experience** (`/dashboard`)
   - Sees startup metrics in real-time
   - **Quick Actions** widget suggests easy first moves
   - Clicks "Quick Hire" → Instantly hires first engineer
   - Sees metrics update immediately
   - **Achievement Unlocked:** "Entrepreneur" (first startup)
   - **Notification appears:** +100 XP, Level 1 progress shown

4. **Gets Advice** (Proactive prompt)
   - Low runway triggers advisor alert
   - "Sarah Chen (CEO) wants to talk" notification
   - Clicks notification → Redirected to `/advisors`
   - Chat with CEO about runway management
   - Gets practical advice: "You need revenue or fundraising"
   - **Achievement Unlocked:** "Seeking Wisdom" (first advisor chat)

5. **Makes Strategic Decision**
   - Returns to dashboard
   - Sees "Decision Recommendations" panel
   - Chooses "Fundraise" decision
   - Gets input from CEO, CFO, and Investor
   - Makes informed choice: Angel Round ($100k)
   - **Achievement Unlocked:** "Revenue Machine" (when hits $10k MRR)

6. **Profile Growth** (`/profile`)
   - Checks profile to see progress
   - Level 2! (+600 XP from achievements)
   - 3 achievements unlocked
   - Decision history shows learning from choices
   - Sees next goals: "Join your first competition"

### Path B: Experienced Founder

1. **Landing Page** (`/`)
   - Clicks "Try Demo" → Skips straight to action

2. **Onboarding Flow**
   - Chooses "I Know Startups"
   - Fast-tracked through features
   - Skips tutorial details

3. **Immediately Competes** (`/compete`)
   - Joins Head-to-Head competition
   - Familiar with startup metrics
   - Uses poaching and sabotage strategically
   - Wins first competition
   - **Achievement Unlocked:** "Victor" (+1000 XP, Level 3)

4. **Becomes Regular Competitor**
   - Joins tournaments
   - Climbs leaderboards
   - Unlocks "Win Streak" achievements
   - Level 10+ (experienced player)

## Journey 2: Solo Player → Strategic Decision Maker

**Goal:** Learn from AI advisors and improve decision-making skills

### The Learning Path

1. **Starts Simulation** (`/dashboard`)
   - Running a B2B SaaS startup
   - Day 45: User growth is stalling
   - Burn rate is high, runway dropping

2. **Crisis Point**
   - **Proactive Alert:** CFO notices burn rate > 3x MRR
   - Notification: "David Park (CFO) flagged a concern"
   - User clicks → Opens advisor chat

3. **Multi-Advisor Consultation** (`/advisors`)
   - Asks CFO: "How do I reduce burn without hurting growth?"
   - CFO suggests: "Cut non-essential hires, optimize marketing spend"
   - Asks CMO: "How can I grow faster with less budget?"
   - CMO suggests: "Focus on viral loops, content marketing"
   - **Board Meeting:** Calls emergency meeting
   - All 5 advisors discuss the situation
   - Gets consensus: Pivot to focus on retention > acquisition

4. **Implements Strategy**
   - Uses Decision Panel
   - Executes: Fire non-performing employees
   - Executes: Shift marketing to content
   - Executes: Build retention features
   - **Decision History** tracks all choices

5. **Sees Results** (3 months later)
   - Burn rate down 40%
   - User retention up 25%
   - MRR growing steadily
   - **Achievement Unlocked:** "Cockroach Founder" (survived on low burn)
   - **Level Up:** Level 5 → unlocks Advanced Scenarios

6. **Reviews Learning** (`/profile`)
   - Decision History shows:
     * 3 successful pivots
     * 85% decision success rate
     * Net impact: +320
   - **Achievement Unlocked:** "Master Pivotter"
   - Analytics show strongest skill: Financial Management

## Journey 3: Competitive Player → Tournament Champion

**Goal:** Master multiplayer competition and climb leaderboards

### The Competitive Path

1. **Discovers Multiplayer** (`/compete`)
   - Sees 3 competition modes
   - Starts with Head-to-Head (1v1)
   - Matches with opponent of similar skill

2. **First Battle**
   - Both start with $10k in B2B SaaS market
   - Player focuses on user acquisition
   - Opponent focuses on revenue
   - **Turn 15:** Player uses "Poach Employee"
   - Offers $60k → Success! Steals engineer
   - Opponent's morale drops
   - **Live Feed** shows all actions
   - **Leaderboard** updates in real-time

3. **Strategic Sabotage** (Learns advanced tactics)
   - Joins Tournament mode (sabotage enabled)
   - Battles 4 opponents simultaneously
   - Day 30: Uses "Bad Press" attack on leader
   - Leader's growth rate drops 5%
   - Player overtakes in rankings
   - **Achievement Unlocked:** "Master of Chaos"

4. **Tournament Victory**
   - Final day: Neck and neck with last opponent
   - Quick decision: Hire 2 sales reps
   - MRR spikes
   - Wins by 50k points!
   - **Achievement Unlocked:** "On Fire" (3 win streak)
   - **Level Up:** Level 8 → tournament access

5. **Spectator Mode** (Watching others)
   - Friends share competition link
   - Spectates friend's tournament
   - Sees strategies, learns new tactics
   - Gets inspired to try different approaches

6. **Profile Showcase** (`/profile`)
   - 12 competitions won
   - Win rate: 75%
   - 23 employees poached
   - Top 10 on global leaderboard
   - All competition achievements unlocked

## Journey 4: Session Continuity → Long-Term Player

**Goal:** Build habit through session persistence and progression

### The Retention Path

1. **Day 1: Initial Excitement**
   - Plays for 2 hours
   - Builds startup to 500 users
   - Unlocks 3 achievements
   - **Auto-save** runs every 30 seconds
   - Closes browser

2. **Day 3: Returns**
   - Opens FounderMind
   - **Session Restore** prompt appears
   - "Continue from Day 87? (500 users, $5k MRR)"
   - Clicks "Continue"
   - Exactly where they left off
   - **Daily Challenge** notification appears

3. **Week 2: Routine**
   - Checks in daily
   - Each session: Make 2-3 decisions
   - Track progress on `/profile`
   - XP bar fills steadily
   - **Level 6:** Unlocks new features

4. **Month 1: Invested**
   - Has 4 active startups
   - Won 8 competitions
   - 15 achievements unlocked
   - Level 10 (1% of players)
   - **Achievement Unlocked:** "Master Historian" (all scenarios complete)

5. **Month 3: Community**
   - Shares achievements on social media
   - Invites friends to compete
   - Creates custom scenarios
   - Becomes mentor to new players

2. **Increase Advisor Engagement**
   - Add more proactive alerts
   - Context-aware suggestions
   - Urgent vs. casual advice levels

3. **Gamification Hooks**
   - Daily login bonuses
   - Limited-time challenges
   - Seasonal tournaments
   - Exclusive achievements

4. **Social Features**
   - Friend leaderboards
   - Team competitions
   - Mentor/mentee matching
   - Community scenarios
